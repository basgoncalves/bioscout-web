File formats

Everything BioScout Web will read, and everything it writes. Nothing on this page leaves your device.

Import

There is exactly one import format, and every Import button in the app — training, sleep, vitals, Edit profile — opens the same one. It reads the whole file and merges whatever it finds, so a file that only carries sleep still imports fine from the Sleep button.

FormatWhat it is
.json
BioScout export		 A file BioScout itself wrote, with "format": "bioscout-profile-export" at the top. Make one under Edit profile → Export on the device that has the data. It carries profiles, sessions, meals, water, diary, weight, cycle, sleep, vitals, cardio and filed assessments — everything except photos and the analysed curves.

Importing is additive: nothing already on this device is deleted or overwritten by an import, and importing the same file twice adds nothing the second time. A file written by a newer version of BioScout than the one you are running is refused rather than half-read.

Not accepted (yet)

These are the files people most often try. None of them work today, and the app will say so rather than import something wrong:

  • Watch and phone exports — Garmin, Amazfit / Zepp, Fitbit, Polar, Apple Health, Google Fit, Samsung Health, Withings.
  • Activity files — .fit, .tcx, .gpx.
  • Spreadsheets — .csv, .xlsx. BioScout writes CSV but does not read it.
  • Motion files — .mot, .sto, .trc, .c3d.

Until one of these is supported, the way in is to type the numbers into the Sleep and Vitals boxes on the day they belong to, or to convert your export into the BioScout JSON above.

Video for analysis

Analyse a video file takes any video your own browser can play — there is no separate decoder, so if the clip opens in the browser it will analyse.

  • .mp4 (H.264) is the safest everywhere.
  • .webm and .mov usually work; a .mov in Apple ProRes, and HEVC on some browsers, will not.
  • Frame rate is read from the clip. Nothing is uploaded: the pose model runs on this device, on this file.

What BioScout writes

FileContents
.jsonThe export above — the only file that can be imported back in.
.motJoint angles per frame, in OpenSim motion format, signed for the model named on the results card.
.stoJoint moments, where the movement and the camera view allow them to be computed.
.zipEverything for the session: the files above, per-rep CSVs, a README explaining each one, and the video if you ticked that box.
